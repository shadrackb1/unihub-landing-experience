# Pre-ship checklist

Run after any copy or marketing UI change.

## Writing
- [ ] Banned words gone
- [ ] Em dashes ≤ 1 on the page (ideally 0)
- [ ] No "not just X, but Y"
- [ ] No fake metrics or testimonials
- [ ] Facts/prices/campuses unchanged
- [ ] Sentences vary in length
- [ ] Active voice

## UI
- [ ] No instructional chrome about motion/video
- [ ] CTAs name real actions
- [ ] Titles use `·` or plain words
- [ ] Focus states still present
- [ ] Mobile copy does not overflow awkwardly

## Project
- [ ] `npm run build` passes
- [ ] Commit + push when user wants changes live
